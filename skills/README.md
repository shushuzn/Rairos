## Adding Skills

To add new skills:

1. Create a new `.md` file in this directory
2. Follow the [Agent Skills specification](https://agentskills.io/specification)
3. Include frontmatter with `name`, `description`, `version`, `tags`

## Installation

Skills are installed to the AI agent's skills directory. Use:

```bash
npx skills add <skill-source>
# or
gh skill install <skill-source>
```
