AI Research OS — Architecture

Self-Evolving Research Operating System — paper ingestion, knowledge graph, RAG, and autonomous research loop

Input Sources

  • • arXiv ID or URL (arxiv.org/abs/...)
  • • DOI (doi.org/10.xxx/...)
  • • Local PDF files (scanned or text)
  • • RSS-style paper subscriptions

Output Structures

  • • P-Note — per-paper key insight
  • • C-Note — per-concept aggregated note
  • • M-Note — 3+ paper comparison
  • • Radar — topic frequency heat score
  • • Timeline — year-based evolution

Key Integrations

  • • Ollama (nomic-embed-text, 768-dim)
  • • OpenAlex citation graph
  • • DashScope / OpenAI for AI drafts
  • • EvoSkill for self-evolution
