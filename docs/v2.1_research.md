## HN Trend Analysis

### 1. AI Agent Frameworks (Flue, DAC, Pollen WASM)
AI agents are exploding. Developers want **local, self-hosted agent runtimes** with zero infrastructure dependency.
- *Opportunity for Rairos:* Research agents that run autonomously on local hardware, not cloud.

### 2. Local-First AI (mljar Studio pattern)
"Local AI data analyst" resonates — people want AI that runs on their machine.
- *Opportunity for Rairos:* Ollama integration is already there; lean harder into "local-first research OS".

### 3. Self-Evolution as a Feature (Gene Pool is unique)
No other research tool has a self-evolving memory. This is Rairos's moat.
- *Opportunity for Rairos:* Make the evolution visible — dashboard, weekly digest, learning log.

### 4. Open Design / AI-as-Design-Engine
AI coding agents being used for design workflows.
- *Opportunity for Rairos:* paper2code pipeline could generate experimental code from papers autonomously.

### 5. Battery / Energy Research, Climate AI
Battery reuse patents 7x, fungal island remediation.
- *Opportunity for Rairos:* arXiv watch + Gene Pool could auto-flag energy/climate papers.

### 6. DeepSeek V4 — Cheap Frontier AI
Cost collapse of AI inference enables always-on research loops.
- *Opportunity for Rairos:* autonomous research loop becomes economically viable.

### 7. Learning During Sleep / Dream Research
People can communicate and practice skills while dreaming.
- *Wildcard:* Research OS could generate "dream briefs" — summaries generated during off-peak hours.

### 8. Autonomous Vehicles / Sensor Grids
Uber monetzies driver vehicles as sensor data.
- *Analog:* Rairos could treat researchers as "knowledge sensors" — their browsing patterns become signals.

## v2.1 Feature List (20+)

### Web UI (v2.1 Core)

**F1 — Web Chat Interface**
- Full web-based chat session (mirrors `chat-tui` in browser)
- Persistent session history, search past conversations
- Sessions stored in `~/.ai_research_os/chat_sessions/`
- Route: `GET /chat`, `POST /chat/send`
- Auth: optional API key gate

**F2 — Research Briefing Generator**
- One-click "Generate Briefing" button in web UI
- Reads Gene Pool + recent papers + trend analyzer
- Renders as hand-drawn web page (matching existing aesthetic)
- Route: `POST /briefing/generate`

**F3 — Session Persistence & Auth**
- Session cookies for web UI (optional PIN lock)
- Session history searchable, exportable as JSON/Markdown
- `WEB_PASSWORD` env var for optional password protection

**F4 — Docker-Production Quickstart**
- `docker compose up` immediately gives working web UI at localhost:8501
- Ollama auto-downloads `nomic-embed-text` model on first start
- Health check endpoint `GET /health`

**F5 — Gene Pool Dashboard (Web)**
- Visualize all capsules: status colors, scores, gap_type distribution
- Click a capsule → see full metadata + citation paths
- Filter by status, gap_type, polarity, score range
- Route: `GET /gene-pool`

**F6 — Contradiction Visualizer (Web)**
- Show contradiction pairs as edge graph (same gap_type, opposite polarity)
- Highlight shared keywords, show paper titles
- Route: `GET /contradictions`

**F7 — Paper Detail → Gene Pool Linking**
- In paper detail page: show Gene Pool Relevance card
- "Extract Gap" button → calls LLM → shows preview → confirms save
- Route: `GET /paper/{id}` already exists; enhance it

### Self-Evolution (v2.1 Intelligence)

**F8 — Evolution Log: Weekly Digest**
- `EvolutionTracker.get_weekly_report()` summarizes:
  - New capsules added, consumed, archived
  - Gap types trending up/down
  - Top contradictions found
- Rendered as email-ready HTML or `/briefing/weekly` page
- Auto-generated every Sunday via `gap watch --digest`

**F9 — Auto-Archive Dashboard**
- Show capsules at risk of auto-archival (low_score_streak ≥ 2)
- Allow manual override: "keep active" button
- Route: `GET /gene-pool/at-risk`

**F10 — Capsule Merge Review**
- Show pending merges (Jaccard ≥ 0.80) before they happen
- User confirms or rejects each merge
- Route: `GET /gene-pool/pending-merges`, `POST /gene-pool/merge/{id}`

**F11 — Gap Type Trend Chart**
- Time-series bar chart of gap_type distribution over last 30/90 days
- Built from capsule `created_at` timestamps
- SVG-rendered (no external chart library needed)

**F12 — Gene Pool Import/Export**
- `POST /gene-pool/import` — accept JSON capsule batch
- `GET /gene-pool/export` — download full pool as JSON
- Useful for backup and sharing configs across machines

**F13 — User Preference Profile (Web)**
- Show `gap_type_preferences` radar chart
- Evolution of preferences over time (which gap_types user accepts/rejects most)
- Route: `GET /profile`

### Autonomous Research Loop (v2.1 Innovation)

**F14 — arXiv Digest Generator**
- `gap watch` collects papers → LLM summarizes top 5 → HTML digest
- Digest emailed or rendered at `GET /digest/arXiv`
- Triggered daily or on demand

**F15 — Research Hypothesis Generator (Auto)**
- Given a Gene Pool gap, generate N hypotheses automatically
- Store hypotheses with `hypothesis_id`, link back to source capsule
- Route: `POST /hypotheses/generate`

**F16 — paper2code Web Runner**
- Upload a paper → web UI triggers paper2code pipeline
- Shows generated code, test scaffold, benchmark plan
- Long-running job with progress indicator (WebSocket or SSE)
- Route: `POST /paper/{id}/code`, `GET /paper/{id}/code/status`

**F17 — Research Session Auto-Archive**
- Sessions idle > 7 days → auto-archive unconsumed gaps
- Configurable via `AIROS_SESSION_TTL_DAYS`

**F18 — Citation Pathfinder Web UI**
- Input paper ID → see full citation tree with Gene Pool highlights
- SVG-rendered interactive graph
- Route: `GET /path/{paper_id}`

**F19 — EvoSkill Discovery Dashboard**
- Show discovered skills from benchmark pipeline
- Rank by improvement delta, show benchmark scores
- Route: `GET /skills`

**F20 — Notification / Webhook System**
- Gene Pool watch matches → trigger webhook (Slack/Discord/email)
- Config via `AIROS_WEBHOOK_URL` env var
- `gap watch --webhook https://hooks.slack.com/...`

**F21 — Multi-Researcher Support (Shared Gene Pool)**
- Multiple users contribute to same Gene Pool
- Each capsule tagged with `source_user`
- Shared pool at `~/.ai_research_os/shared_gene_pool.json`

**F22 — Research Memory TTL**
- Capsules auto-expire after N days unless "pinned"
- `pinned: true` capsules survive TTL
- Route: `POST /gene-pool/{id}/pin`
